# Blue Bay Pin

A Christmas golf game for Blue Bay Golf & Beach Resort. Players pick a hole on the course map,
get tips from golf pro Steffen Kefer, and play it shot by shot.

## Run it

Open `index.html` in a browser. Everything loads from local files, so no server is needed.
To test on a phone on the same Wi-Fi, run `python3 -m http.server 8000` in this folder and
open `http://<your-computer-ip>:8000`.

## Project layout

```
index.html            Page markup: HUD, menu, course map, result card, tutorial
css/style.css         All styles (brand colours are CSS variables at the top)
js/data.js            Holes, course map markers, scorecard, handicaps, Steffen's tips
js/game.js            Game engine: physics, camera, controls, course map, hole card
js/tutorial.js        Steffen's tutorial (first visit, or "How to play" in the menu)
assets/holes/         Hole artwork, one file per hole (hole-N.jpg)
assets/masks/         Surface masks per hole, generated by tools/build_mask.py
assets/course-map.jpg Course overview used for hole selection
assets/steffen.png    Steffen cut-out
assets/blue-bay-logo.png
tools/build_mask.py   Turns hole artwork into a surface mask
tools/bundle.py       Packs everything into one HTML file in dist/
```

## Add a hole

1. Save the artwork as `assets/holes/hole-N.jpg` (remove any ball drawn on the tee).
2. Run `python3 tools/build_mask.py assets/holes/hole-N.jpg N --green X,Y --tee X,Y --pin X,Y`
   and check `tools/preview-hole-N.png`.
3. Add the hole to `window.BB_DATA.holes` in `js/data.js`: size, tee, pin, metres per pixel
   (`m` = real length / tee-to-pin distance in px) and `k` (so a full shot carries about 175 m:
   `k = (175 / m) / 553`).
4. Add Steffen's tips for it under `window.BB_DATA.tips`.
   Check its wind exposure in `window.BB_DATA.exposure` (1 = on the sea, 0 = sheltered).
5. Add `<script src="assets/masks/hole-N.js"></script>` to `index.html`, plus a quick-pick
   button in the menu if you want one.

## Wind and aiming

Wind is the same for every player on a given day: it is seeded from the hole number and the
date in Curaçao (`dailyWind` in `js/game.js`). Holes on the coast get stronger wind
(`BB_DATA.exposure`), and `WIND_FX` sets how hard it pushes the ball. The aim guide shows the
shot in calm air only, so players have to allow for the wind themselves. Putts show a direction
and a rough distance, and only drop when they reach the cup slowly enough (`CUP_SPEED`).

## Tutorial

`js/tutorial.js` holds the steps as a list: each has Steffen's line, whether the player
just reads (`talk`) or acts (`do`), and optionally an element to spotlight. It runs once per
browser (remembered in localStorage under `bb_tutorial_done`) and from "How to play".
The game announces `bb:start`, `bb:shot`, `bb:stopped`, `bb:look` and `bb:holed` events
that the tutorial listens to.

## Publish

`python3 tools/bundle.py` writes `dist/blue-bay-pin.html`, a single self-contained file.
For launch, host the separate files instead so each hole's artwork loads only when needed.
